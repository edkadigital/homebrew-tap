# Edka Homebrew tap

Homebrew formulae for [Edka](https://edka.io).

```sh
brew install edkadigital/tap/edka
```

`edka` is the [Edka CLI](https://github.com/edkadigital/cli), on macOS and Linux. Upgrade it with `brew upgrade edka`. The [documentation](https://edka.io/docs/cli/overview/) covers each command.

Each release of the CLI writes `Formula/edka.rb`. Change the formula in [edkadigital/cli](https://github.com/edkadigital/cli), in `scripts/homebrew-formula.sh`, rather than here.
